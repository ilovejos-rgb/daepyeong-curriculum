선택과목 유형 정리

유형이 여러 개로 잡힌 선택군 안의 과목별 유형을 지정합니다.

사이트 보기
사용 방법 편성표상 한 묶음에 여러 유형이 표시된 선택군의 과목들이에요. 과목별로 실제 유형 하나를 골라주세요. 모두 정한 뒤 "저장" 버튼을 누르면 새 curriculum.json 파일이 다운로드됩니다. 이 파일을 GitHub의 같은 이름 파일에 덮어쓰면 사이트가 업데이트됩니다.

JSON 파일이 다운로드되었어요

다음 단계로 사이트에 반영하세요:

  1. 다운로드 폴더에서 curriculum.json 확인
  2. GitHub 저장소 → 기존 curriculum.json 파일 클릭
  3. 연필 아이콘 → 전체 삭제 후, 새 파일 내용 붙여넣기
  4. 또는 Add file → Upload files로 파일 끌어다 놓기 (덮어쓰기)
  5. 아래 Commit changes 클릭
  6. 1~2분 후 사이트 강제새로고침 (Ctrl/Cmd + Shift + R)
