과목 안내·PDF·유튜브 연결 각 과목의 한 줄 소개, PDF 안내서 시작 페이지 번호, 유튜브 영상 URL을 입력하세요. 과목 카드 클릭 시 학생들에게 표시됩니다.
PDF 설정 과목 안내서 PDF 파일의 경로를 설정합니다. PDF 파일을 GitHub 저장소에 같이 업로드한 후 파일명을 적어주세요.
GitHub 연동 (자동 저장) 여기에 GitHub Personal Access Token을 입력하면, 이제부터 "저장" 버튼을 누르면 GitHub에 자동으로 업로드됩니다. 따로 JSON 파일을 다운받아 올리지 않아도 돼요. (브라우저에만 저장되며 다른 사람에게 노출되지 않습니다)

JSON 파일이 다운로드되었어요

다음 단계로 사이트에 반영하세요:

  1. 다운로드 폴더에서 curriculum.json 확인
  2. GitHub 저장소 → 기존 curriculum.json 파일 클릭
  3. 연필 아이콘 → 전체 삭제 후, 새 파일 내용 붙여넣기
  4. 또는 Add file → Upload files로 파일 끌어다 놓기 (덮어쓰기)
  5. 아래 Commit changes 클릭
  6. 1~2분 후 사이트 강제새로고침 (Ctrl/Cmd + Shift + R)
